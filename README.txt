HER CARE — Revised Website Prototype
===================================

This version was revised to align with the attached HERCARE project requirements.

HOW TO OPEN
1. Extract the ZIP file.
2. Open the "her-care" folder.
3. Double-click index.html.

FILES
- index.html — page structure and content
- styles.css — responsive styling
- app.js — package selection, midwife profiles, booking flow, Ask HerCare, local demo storage

MAIN REVISION AREAS
- Repositioned HerCare as a midwife-led HOME CARE service.
- Updated hero message to "Personalized Midwifery Care, Right at Your Doorstep."
- Added detailed Prenatal Home Services, First-Time Mother Care, Postpartum Home Care, and Maternal Immunization Service.
- Added project sample packages and prices.
- Added six-step home-visit booking flow:
  1) Service
  2) Package
  3) Schedule
  4) Midwife
  5) Home visit details
  6) Confirmation
- Added Midwife A/B/C cards and "any available midwife" option.
- Added Ask HerCare question form and example.
- Added Designed for Working Mothers and HerCare Promise sections.
- Added appropriate emergency and immunization-scope notices from the project requirements.

DEMO NOTE
Bookings and questions are stored only in the current browser's localStorage. This is a front-end prototype and does not send data to a server.
